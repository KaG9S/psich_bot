# Psich_bot template

This is open-source template for projects that want to use already existing programs and commands,
not writing new by himself

## Configure

Configure your [start.env](./start.env) file with this data
- bot token
- admin id and username
- manager id and username

Then, configure texts in different files from src/decos
- [start](src/decos/start.py)
- [admin panel](src/decos/admin_panel.py)
- etc.

Also, you can add custom decorators and triggers for different messages:
- create new file in src/decos directory
- edit decorators
- fork files
